# Adyan's 2-Player Checkers (Microsoft Edge Extension)

A local 2-player Checkers game for Microsoft Edge with customizable house rules and zero internet required.

## Features
- **Custom Rule Toggles:** Forced Captures, Chain Take, Take Longest Chain, Threefold Repetition, and White Plays First (all off by default).
- **Smooth Animations:** Pieces glide across the board when moved.
- **Victory Screen:** Celebratory trophy screen and confetti animation when a player wins.

## How to Install in Microsoft Edge
1. Click the green **<> Code** button at the top of this page and select **Download ZIP** (or download the ZIP from **Releases** on the right).
2. Extract (unzip) the downloaded folder on your computer.
3. Open Microsoft Edge and go to `edge://extensions`.
4. Turn on **Developer mode** in the bottom-left corner.
5. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
6. Click the **Extensions puzzle icon** in your Edge toolbar and open **Adyan's 2-Player Checkers** to play!
